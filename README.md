# 意大利史诗 · STORIA D'ITALIA

从罗马文明到现代意大利 —— 一部可长期阅读的意大利历史数字图书馆。

## 项目简介

这是一个**移动端优先**的意大利历史沉浸式阅读网站，以三本经典历史著作为核心参考，系统呈现意大利从史前到当代的完整历史脉络。

**核心原则：阅读为主，学习为辅。** 这不是考试平台，而是一部结构严谨、内容丰富的数字历史著作。

## 参考书目（真实取材）

1. **《意大利简史》**（Italy: A Short History）— Harry Hearder / Jonathan Morris 修订
   - 提供意大利历史的整体框架（从史前到现代共和国）
2. **《命运的力量》**（The Force of Destiny，意大利文版 La forza del destino）— Christopher Duggan
   - 深入研究 1796 年以来的近现代史（统一运动、自由主义、法西斯、共和国）
3. **《意大利文艺复兴时期的文化》**（中译本）— 雅各布·布克哈特
   - 文艺复兴专题（结合现代研究修正 19 世纪观点）

> 说明：三本书已提取文本至 `.source/` 目录，作为写作的事实与叙事依据。正文均为**独立撰写**的历史叙述，未伪造原文引用或页码；对争议问题（如马基雅维利评价、罗马衰落、抵抗运动记忆等）已呈现不同学术观点。

## 内容规模

- **94 个章节**（8 个部分），正文总字数约 14.4 万字，平均每章 1500+ 字
- **15 个专题档案**（罗马制度、威尼斯、美第奇、马基雅维利、南北差异等）
- **20 位人物档案**（凯撒、奥古斯都、但丁、达·芬奇、加富尔、墨索里尼等）
- **11 张交互式历史地图**（SVG，支持缩放/高亮）
- **53 个时间轴事件**

## 功能

- 连贯长篇正文 + 清晰章节目录
- 上一章 / 下一章导航
- 阅读位置自动记忆（本地 localStorage）
- 个人书签、个人阅读笔记
- 全文搜索
- 历史人物 / 事件关联跳转（`.entity` 标记）
- 交互式历史时间轴
- 交互式历史地图（缩放、区域高亮）
- 图片灯箱放大查看

**明确不包含**：测验、选择题、积分、打卡、排行榜等考试型功能。

## 技术架构

纯前端 SPA，无外部依赖，加载快、可离线运行：

```
index.html          — 应用入口
styles.css          — 文艺复兴主题样式（移动端优先）
app.js              — 应用逻辑（路由、进度、书签、笔记、搜索、地图）
data/
  core.js           — 全局数据结构（8 个部分定义）
  part1~8.js        — 94 章正文（按历史时期分 8 个文件，便于扩充）
  topics.js         — 15 个专题档案
  people.js         — 20 位人物档案
  maps.js           — 11 张 SVG 历史地图
  timeline.js       — 历史时间轴
```

### 内容数据结构（便于持续扩充）

章节对象规范（见 `core.js` 注释）：

```js
{
  id: "c1", part: "p1", num: 1,
  title: "史前意大利与早期文明",
  sub: "副标题",
  period: "时间范围",
  words: 2100,
  body: `<p>...</p>...`  // HTML 富文本
}
```

关联跳转：正文中用 `<span class="entity" data-entity="ID">名称</span>`
图片：`<figure class="figure"><img data-src="..."><figcaption>...</figcaption></figure>`

## 本地运行

```bash
cd 项目目录
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899
```

（也可直接双击 `index.html`，但推荐用本地服务器以获得最佳体验。）

## 视觉设计

文艺复兴图书馆主题：象牙白、深酒红、古典墨绿、暗金、深棕，衬线字体。参考美第奇宫、乌菲兹美术馆、威尼斯总督宫、梵蒂冈博物馆的视觉气质。
